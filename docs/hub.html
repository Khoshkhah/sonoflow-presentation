Pillar 1 · The Urban Reality

4.3% Counted. 95.7% Inferred.

Modern cities only instrument major corridors. In Södermalm, 195 induction sensors measure 4,563 directed street edges. SonoFlow predicts the unmeasured network with honest Bayesian calibration.

Measured Edges (195)

Carries live count observations. Kalman updating contracts uncertainty to a tight ±1.15× interval.

Inferred Edges (4,368)

Never counted. Estimated through 3-hop turn-graph conservation and road-class diurnal shape priors.

Calibrated Guarantee

80% prediction intervals contain the ground truth 79.9% of the time on held-out validation streets.

Pillar 2 · Mathematical Model

Two-Scale State Decomposition

Traffic decomposes into a log-baseline level $L(e)$ and a normalized weekly diurnal shape $ ho(e, w, h)$ constrained to integrate to $1.0$.

Flow(e, d, h) = exp( L(e) + λ(c)·f(d) + k(d) ) · ρ(e, w(d), h)

1. Baseline Level L(e)

Tracks permanent volume using Kalman filtering with daily random-walk drift σdrift ≈ 0.05/year.

2. Weekly Diurnal Shape ρ

4 Day Groups (Mon–Thu, Fri, Sat, Sun) × 24h shapes shrunk towards class anchors.

Pillar 3 · Bayesian Honesty

Estimate Mode vs. Forecast Mode

Knowing the day's city-wide conditions produces tight estimates. Forecasting future dates widens the interval honestly via prior variance $C$.

Var_Estimate = v(e) + σ_shape² + σ_anyday²
Var_Forecast = Var_Estimate + λ(c)² · C_prior

Estimate Mode (80.3% Honest)

Median error ×1.10. Uses live day factor f(d) computed across all active urban sensors.

Forecast Mode (Honest Widening)

Median error ×1.15. The 5-point widening penalty reflects the real risk of future date forecast.

Pillar 4 · Macro Change Detection

CUSUM Disruption Monitoring

Tracks cumulative displacement of network day factors to detect true structural shifts (pandemic lockdown, bridge openings) without false alarms.

CUSUM Algorithm
